DIY Manus / local-first general agent

A working, self-hosted take on Manus: an agent that plans, uses tools, and delivers real files — running entirely on your machine. No cloud keys. No data leaving your network.

100% local by default ollama · qwen2.5:3b keyless web search SQLite session memory MIT

Quickstart

git clone https://github.com/nitishagar/diy-manus.git
cd diy-manus
make setup                                  # venv + deps + ollama + model pull
make run TASK="create hello.txt containing hi"
make smoke                                  # end-to-end local test

Needs Python 3.10+, ollama, and make. On a CPU-only laptop expect ~30–60 s per agent step; tasks are typically 3–15 steps.

How it works

The same agent-loop shape Manus describes publicly: each iteration the model picks one tool call, the tool executes locally, and the observation is appended to an append-only context. The agent keeps its plan in todo.md, adapts after errors, and terminates on finish, repeated failures, or the step limit — never loops forever. Every step is traced live and stored for replay.

shell_exec

bash in your workspace; output size-capped, killed at timeout, process group reaped.

file_read / write / list

Hard-confined to the workspace — path traversal and symlink escapes are refused.

web_search / web_fetch

Keyless DuckDuckGo search (or your own SearXNG) + readable-text extraction. No API keys.

browser tools

Optional local Playwright Chromium; degrades to a clear "unavailable" note if not installed.

recall

Full-text search over past local sessions (SQLite FTS5) — memory without the cloud.

replay

manus --list and manus --replay <id> re-show every step of a run.

Bring your own model

Defaults are local (qwen2.5:3b via ollama — chosen because small thinking models burn their budget before emitting tool calls on CPU). Any OpenAI-compatible endpoint works by pointing MANUS_BASE_URL, MANUS_MODEL, MANUS_API_KEY at it — zero code changes.

Safety

The shell tool runs real commands on your machine, confined to the workspace directory. It is a convenience, not a security boundary. A Docker-sandboxed shell is the top roadmap item.
